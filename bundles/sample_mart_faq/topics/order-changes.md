# 주문 후 변경

주문 후 변경은 대부분 주문상태가 결제완료일 때만 된다. 상품준비중·배송중이면 변경할 수 없다.

## 배송지 변경

* **[주문 후 배송지 변경 조건](../faqs/purchase/faq-174.md)**: 결제완료 상태이고 같은 매장에서 배송되는 주소일 때만 상세주소를 바꿀 수 있다. 상품준비중·배송중이거나 다른 매장 배송지면 바꿀 수 없다.[^faq-174]
* **[배송지 변경 방법](../faqs/purchase/faq-251.md)**: 주문 상품 모두가 결제완료일 때 바꿀 수 있고, 매직배송과 판매자 택배를 함께 주문했다면 모든 상품의 배송지가 같이 바뀐다.[^faq-251]

## 상품 추가와 취소

* **[합배송 주문 마감](../faqs/purchase/faq-234.md)**: 합배송은 예약한 배송건의 상품 준비 전(결제완료 상태)까지 신청한다.[^faq-234]
* **[주문 후 일부 상품 추가·취소](../faqs/purchase/faq-239.md)**: 매직배송은 결제완료 때 추가주문(합배송)으로 배송비 없이 더하거나 일부를 취소한다. 조건부 무료배송이 깨지면 배송비를 빼고 환불한다. 판매자 택배는 상품별 부분취소만 된다.[^faq-239]
* **[추가주문(합배송) 서비스](../faqs/purchase/faq-240.md)**: 매직배송 일반배송 주문은 상품 준비 전까지 배송비 없이 추가 주문할 수 있고, 합산 금액으로 배송비를 다시 계산해 차액을 마일리지로 돌려준다. 예약배송·판매자 택배·매직나우는 제외다.[^faq-240]
* **[택배상품 추가·옵션 변경](../faqs/purchase/faq-241.md)**: 결제가 끝난 택배상품은 옵션 변경이나 추가 주문이 안 되며, 결제완료 상태에서 취소 후 다시 주문한다.[^faq-241]

## 품절과 대체

* **[주문 상품 품절 처리](../faqs/purchase/faq-105.md)**: 대체 선택에 따라 취소되거나 비슷한 상품으로 대체되고 알림톡·문자로 알린다. 비싼 상품으로 대체되면 차액은 무상, 싼 상품이면 환불한다. 유아용품·가전·완구 등은 대체되지 않는다.[^faq-105]
* **[품절 시 대체 안 받기](../faqs/purchase/faq-208.md)**: 결제 때 장바구니 전체나 상품별로 대체·대체안함을 고른다. 대체를 골라도 비슷한 상품이 없으면 취소된다.[^faq-208]
