# 교환과 반품

교환은 같은 상품으로만 된다. 다른 상품을 원하면 환불받고 다시 주문한다. 신선식품은 단순 변심으로 교환·반품할 수 없다.

## 조건

* **[교환·반품이 안 되는 경우](../faqs/claim/faq-068.md)**: 고객 책임의 분실·훼손, 포장 훼손으로 가치가 크게 떨어진 경우, 사용·시간 경과로 가치가 떨어진 경우, 복제 가능한 상품 포장 훼손, 신선식품 단순 변심은 안 된다.[^faq-claim-068]
* **[하자 상품 다른 상품으로 교환](../faqs/claim/faq-152.md)**: 하자 상품 교환은 같은 상품만 된다. 다른 상품을 원하면 환불받고 다시 주문하며, 새 주문 배송비는 고객이 낸다.[^faq-claim-152]

## 접수 방법

* **[매직배송상품 교환·반품](../faqs/claim/faq-202.md)**: 배송완료 뒤 1:1 문의로 접수하거나 배송받은 매장 고객서비스센터에 반납한다. 변심 반품은 반품배송료가 붙을 수 있다.[^faq-claim-202]
* **[품질·유통기한 불만 교환](../faqs/claim/faq-186.md)**: 배송 때 발견하면 기사에게, 배송 후면 1:1 문의로, 매장 방문이 되면 고객서비스센터에서 같은 상품으로 교환·반품한다.[^faq-claim-186]
* **[유통기한 불만](../faqs/claim/faq-189.md)**: 배송 때는 기사에게, 배송 후에는 1:1 문의나 주문배송조회 교환/반품신청으로 접수하고, 구매 점포 고객센터에서도 된다.[^faq-claim-189]

## 처리와 확인

* **[판매자 택배 교환·반품 처리 기간](../faqs/claim/faq-077.md)**: 상품을 보낸 뒤 보통 1주일, 주말·공휴일이 끼면 약 10일 걸린다.[^faq-claim-077]
* **[반송장번호란](../faqs/claim/faq-119.md)**: 수거 때 택배기사가 주는 용지의 송장번호로, 환불 완료 전까지 보관하고 고객센터에 알려 준다.[^faq-claim-119]
* **[판매자 택배 반품을 잘못 보냈을 때](../faqs/claim/faq-091.md)**: 반송장의 반송날짜·택배사·반송장번호·반송지 주소를 확인해 1:1 문의로 알린다.[^faq-claim-091]
