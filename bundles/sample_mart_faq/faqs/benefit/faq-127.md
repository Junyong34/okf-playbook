# 답변

샘플마트 온라인 구매 시 고객님의 멤버십 정보로 멤버십 회원을 인증하시면 포인트 적립이 가능합니다.[^sample-faq]

회원님께서 가입하신 멤버십 유형에 따라, 사용하신 결제 카드에 따라 포인트 적립액은 상이합니다.[^sample-faq]

\[샘플마트 내 구매 시\][^sample-faq]

- 일반 멤버십 : 0.1% 적립[^sample-faq]

- 체크 멤버십 : 1.0% 적립 (단, 해당 체크카드로 결제 시)[^sample-faq]

- 신용 멤버십 : 2.0% 적립 (단, 해당 신용카드로 결제 시)[^sample-faq]

- 기타 제휴카드 : 기타 마이 샘플마트와 제휴된 삼성카드, 신한카드 결제 시 추가 포인트 적립[^sample-faq]

\[샘플마트 외 구매 시\][^sample-faq]

- 체크 멤버십 : 1.0% 적립 (단, 해당 체크카드로 결제 시)[^sample-faq]

- 신용 멤버십 : 0.5% 적립 (단, 해당 신용카드로 결제 시)[^sample-faq]
