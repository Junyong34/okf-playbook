# 답변

쿠폰의 종류에 따라 사용법이 다릅니다.[^sample-faq]

- 상품쿠폰 : 상품당 1개 쿠폰만 적용 (적용 수량은 쿠폰에 따라 다름)[^sample-faq]

- 장바구니쿠폰 : 1개 주문에 1개 쿠폰만 적용 가능(단, 매직배송/판매자 택배상품 각각 1장의 쿠폰만 사용가능)[^sample-faq]

- 배송비쿠폰 : 주문시 할인 차감한 총 구매금액 기준에 적용 (한 주문당 1개만 적용)[^sample-faq]

- 마일리지 : 결제 시 할인 받고자 하는 금액을 10P 단위로 자유롭게 사용 가능하며 상품쿠폰, 장바구니쿠폰과 중복 할인 가능. 10P는 10원과 동일하게 사용할 수 있습니다.[^sample-faq]
