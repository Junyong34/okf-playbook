# 반품 조건           ← 본문 (Markdown)

[반품 예외](return-exceptions.md)
[환불 절차](/processes/refunds.md)
  • UTF-8 .md, 맨 위 --- 로 열고 닫는 YAML frontmatter + 본문. §4
  • 항상 필요한 키는 비어 있지 않은 type 하나. type만 있어도 적합. §4.1
  • type 값은 중앙 등록이 없다. 직접 고른다. §4.1
  • 추가 키는 자유. 소비자는 모르는 키로 문서를 거부하지 않는다. §4.1
  • 본문은 제목·목록·표 같은 구조적 Markdown을 권장. §4.2

번들 구조와 예약 파일

파일규칙근거
index.md어느 디렉터리에나 선택적으로. 제목 아래 * [제목](경로) - 설명 목록. frontmatter 없음. 단, 번들 루트 index.md만 okf_version: "0.2" 가능.§8 · §12
log.md어느 수준에나 선택적으로. ## YYYY-MM-DD 날짜 묶음, 최신순.§9
그 밖의 .md모두 개념 문서. 예약 이름은 개념 문서에 쓸 수 없다.§3.1

링크와 경로

형식예 (policies/returns.md 안에서)해석
번들 루트 기준 (권장)/processes/refunds.mdprocesses/refunds.md
문서 기준 상대../processes/refunds.mdprocesses/refunds.md
같은 디렉터리return-exceptions.mdpolicies/return-exceptions.md

주의: 일반 Markdown 미리보기와 GitHub는 /를 저장소 루트로 해석한다. 번들이 저장소 하위 디렉터리(knowledge/)에 있으면 번들 루트 기준 링크가 미리보기에서 깨진다. 이 실습의 링크 형식 팀 규칙은 레슨 0002에서 정한다.

링크는 관계가 있다는 것만 말한다. 어떤 관계인지는 주변 문장이 말한다. 끊어진 링크는 잘못된 것이 아니라 아직 안 쓴 지식일 수 있다. §6.1

적합성: 오류와 경고의 경계

적합하지 않음 (오류)

  • 예약 파일이 아닌 .md에 파싱 가능한 frontmatter가 없다
  • frontmatter에 비어 있지 않은 type이 없다
  • index.md·log.md가 §8·§9 구조를 어긴다

거부 금지 (경고 수준)

  • 선택 필드 누락
  • 모르는 type 값, 모르는 추가 키
  • 끊어진 링크
  • index.md 누락

출처: §11 Conformance.

용어집

번들 (bundle)
개념 문서를 담은 디렉터리 트리. 배포 단위. 이 실습에서는 knowledge/. §2, §3
개념 (concept)
번들 안의 지식 한 단위 = Markdown 파일 하나. 레슨에서는 "문서" 대신 이 말을 쓴다. §2
개념 ID
번들 루트 기준 경로에서 .md를 뺀 값. frontmatter에 쓰지 않는다. knowledge/policies/returns.md → policies/returns. §2
frontmatter
파일 맨 위 --- 사이의 YAML 메타데이터. §2
본문 (body)
frontmatter 뒤의 모든 내용. §2
링크 (link)
개념에서 개념으로 가는 일반 Markdown 링크. §2, §6
인덱스 (index)
디렉터리의 index.md. 문서를 열기 전에 무엇이 있는지 보여 주는 목차(점진적 공개). §8
생산자 / 소비자
번들을 쓰는 쪽(사람, 에이전트, 내보내기 파이프라인) / 읽는 쪽(에이전트, UI, 검색 색인, 코드). §1 Goals
적합 (conformant)
§11의 세 조건을 만족하는 상태. §11
출처 (source)
개념이 근거로 삼은 자료. frontmatter sources에 기록. §2, §5.1
행위자 (actor)
누가 했는지 나타내는 문자열. human:<id>, <producer>/<version>, process:<id>. §7
검색 단계 (retrieval)
RAG에서 질문에 맞는 개념을 골라 오는 단계. 이 실습에서는 retrieve.ts가 맡는다. Lewis et al.
생성 단계 (generation)
고른 본문을 입력으로 모델이 답을 쓰는 단계. Lewis et al.
근거 경로
답변의 주장 옆에 붙이는 개념 파일 경로. 이 실습에서 정한 용어. 학습 계획 §4
