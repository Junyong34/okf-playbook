2026-11-19 OKF v0.3 기준으로 갱신했다. v0.2에서 바뀐 점은 docs/okf-v0.3-changes.md에 있다. 이 레슨에서 가장 크게 바뀐 곳은 type이 없는 파일의 판정(오류 → 경고)과 루트 index.md 규칙이다.

왜 이것이 다음인가

4회차 검색기는 번들을 소비자로서 읽는다. 소비자는 문제가 있는 번들도 끝까지 읽어야 하므로, 무엇이 진짜 오류이고 무엇이 경고인지 코드가 알고 있어야 한다. 오늘 만드는 validateBundle은 파일 시스템을 모르는 순수 함수라서 4회차 검색기와 나중의 웹 화면이 그대로 가져다 쓴다.

0. 회상

노트 없이 답한 뒤 펼친다.

명세 위반이라 오류인 것과, 거부하면 안 되어 경고에 그치는 것을 두 개씩 꼽는다.

오류: frontmatter 블록이 YAML 매핑으로 파싱되지 않음, 예약 파일(index.md·log.md)이 §8·§9를 어김. 거부 금지: 끊어진 링크, 모르는 type, 확장 키, 선택 필드 누락, index.md 누락. v0.3에서는 frontmatter나 type이 없는 .md도 오류가 아니다. 개념이 아닌 파일이라 건너뛰고, 검증기는 경고한다. §11.1§11.2§3.2

/processes/refunds.md가 OKF 소비자와 GitHub에서 다르게 해석되는 이유는?

OKF 소비자는 /를 번들 루트(knowledge/)로, GitHub와 에디터 미리보기는 저장소 루트로 해석한다.§6 그래서 이 실습은 본문 링크에 상대 경로만을 팀 규칙으로 정했다.

frontmatter에 개념 ID를 쓰지 않는 이유는? refunds.md에 resource가 없는 이유는?

ID는 파일 경로에서 정해진다(§2). resource는 가리킬 실물 자산이 있을 때만 쓰는데, 환불 절차는 자산이 없다(§4.1).

1. 명세 규칙과 팀 규칙

검증기는 명세가 정한 것과 우리가 정한 것을 구분해서 보고한다. 팀 규칙은 명세보다 좁을 수 있지만 명세가 허용한 것을 오류로 만들면 안 된다. 다른 소비자에게는 적합한 번들이기 때문이다.§11.2

v0.2 → v0.3에서 바뀐 판정

  • missing-type 오류가 없어졌다. v0.2 §11은 예약 파일이 아닌 모든 .md에 frontmatter와 type을 요구했다. v0.3은 그런 파일을 개념이 아닌 파일로 보고, 검증기에 경고하라고 한다(SHOULD). 그래서 not-a-concept 경고가 되었다. README.md, AGENTS.md 같은 파일을 번들에 둘 수 있게 하려는 규칙이다.§3.2
  • 루트 index.md의 title은 더 이상 오류가 아니다. 루트 frontmatter에는 okf_version, title, description, license와 확장 키를 둘 수 있다. 대신 okf_version이 없으면 missing-okf-version, 따옴표 없는 숫자면 unquoted-version 경고를 낸다.§8.1
  • 새 규칙. log.md에는 frontmatter가 없다(log-frontmatter).§9 시각 값은 오프셋 있는 date-time이나 날짜만 허용한다(bad-timestamp).§5 소비자가 무시할 verified 항목을 미리 알린다(incomplete-verified).§5.2 두 수명 규칙은 0008에서 쓰는 값이다.

YAML 문법 판정은 직접 만들지 않고 yaml 패키지에 맡긴다. 콜론 뒤 공백 누락, 탭 들여쓰기, 중복 키를 모두 예외로 던진다. 탭 금지는 YAML 명세의 규칙이고YAML 6.1, 키 중복 금지는 OKF v0.3 §4의 규칙이다.§4 log.md의 날짜 제목 형식 검사는 이번 범위에서 뺐다.

// ── frontmatter와 본문 나누기 (§4) — 레슨 0003 1단계 ────────────────────
export type Split = { frontmatter: string | null; body: string };

export function splitFrontmatter(text: string): Split {
  // 줄 단위로 나눈다. \r?\n 이라서 Windows 줄바꿈(CRLF)도 같이 처리된다. 맨 앞 BOM도 떼어 낸다.
  const lines = text.replace(/^﻿/, '').split(/\r?\n/);
  // 첫 줄이 '---'가 아니면 frontmatter가 없는 파일이다.
  if (lines[0] !== '---') return { frontmatter: null, body: lines.join('\n') };
  // 두 번째 줄부터 닫는 '---'를 찾는다. 없으면 frontmatter가 닫히지 않은 것이다.
  const close = lines.indexOf('---', 1);
  if (close === -1) return { frontmatter: null, body: lines.join('\n') };
  return {
    frontmatter: lines.slice(1, close).join('\n'), // 두 '---' 사이
    body: lines.slice(close + 1).join('\n'),       // 닫는 '---' 다음 줄부터
  };
}

// ── 링크 경로 해석 (§6) — 레슨 0003 2단계 ─────────────────────────────
// 링크(§6.1)와 경로 필드(§6.2)가 같은 규칙을 쓴다. '/'로 시작하면 번들 루트, 그 밖은 파일이 있는 디렉터리 기준.
// from: 링크가 들어 있는 파일 ("policies/returns.md")
// 반환: 번들 루트 기준 경로, 루트 밖(외부)이면 null
export function resolveLink(from: string, target: string): string | null {
  // 출발점: '/'로 시작하면 번들 루트([]), 아니면 from이 들어 있는 디렉터리.
  const out = target.startsWith('/') ? [] : from.split('/').slice(0, -1);
  for (const part of target.split('/')) {
    if (part === '' || part === '.') continue; // 맨 앞 '/', 겹친 '//', './' 는 건너뜀
    if (part === '..') {
      if (out.length === 0) return null; // 루트보다 위로 가려 함 → 번들 밖
      out.pop();
    } else {
      out.push(part);
    }
  }
  return out.join('/');
}

// 본문에서 번들 안을 가리키는 링크 대상만 뽑는다. 외부 URL·문서 내 앵커·이미지는 제외.
export function extractLinks(body: string): string[] {
  const links: string[] = [];
  for (const m of body.matchAll(/(?<!!)\[[^\]]*\]\(([^)\s]+)[^)]*\)/g)) {
    const target = m[1];
    if (/^[a-z][a-z0-9+.-]*:/i.test(target) || target.startsWith('#')) continue;
    const path = target.split('#')[0];
    try { links.push(decodeURI(path)); } catch { links.push(path); }
  }
  return links;
}

// ── 시각 (§5 Timestamps) ───────────────────────────────────────────────
// 허용 형식은 RFC 3339 두 가지뿐이다.
//  - 오프셋이 있는 date-time: "2026-06-30T14:00:00Z", "2026-11-18T15:00:00+09:00"
//  - 날짜만: "2026-06-30" → 그날 UTC 0시
// YAML 고유 Date 값도 받는다(그날 UTC 0시). 오프셋 없는 date-time과 그 밖 형식은 무효라 null이다.
const DATE_RE = /^(\d{4})-(\d{2})-(\d{2})$/;
const DATETIME_RE = /^(\d{4})-(\d{2})-(\d{2})[Tt](\d{2}):(\d{2}):(\d{2})(\.\d+)?([Zz]|[+-]\d{2}:\d{2})$/;

function validDay(y: string, m: string, d: string): boolean {
  const t = new Date(Date.UTC(Number(y), Number(m) - 1, Number(d)));
  return t.getUTCFullYear() === Number(y) && t.getUTCMonth() === Number(m) - 1 && t.getUTCDate() === Number(d);
}

// 반환: 밀리초 시각, 읽을 수 없으면 null.
export function parseTimestamp(v: unknown): number | null {
  if (v instanceof Date) return Number.isNaN(v.getTime()) ? null : v.getTime();
  if (typeof v !== 'string') return null;
  const d = v.match(DATE_RE);
  if (d) return validDay(d[1], d[2], d[3]) ? Date.UTC(Number(d[1]), Number(d[2]) - 1, Number(d[3])) : null;
  const dt = v.match(DATETIME_RE);
  if (!dt || !validDay(dt[1], dt[2], dt[3])) return null;
  if (Number(dt[4]) > 23 || Number(dt[5]) > 59 || Number(dt[6]) > 59) return null;
  const t = Date.parse(v.toUpperCase());
  return Number.isNaN(t) ? null : t;
}

// yaml 패키지는 콜론 뒤 공백 누락, 탭 들여쓰기, 중복 키를 모두 오류로 던진다.
function parseFrontmatter(src: string): Frontmatter {
  try {
    const data = parse(src) ?? {};
    // "tags:[x]" 한 줄은 매핑이 아니라 문자열로 읽힌다.
    if (typeof data !== 'object' || Array.isArray(data)) return { state: 'invalid', reason: 'frontmatter가 `키: 값` 매핑이 아닙니다.' };
    return { state: 'ok', data };
  } catch (err) {
    return { state: 'invalid', reason: String((err as Error).message).split('\n')[0] };
  }
}

export function readFile(path: string, text: string): BundleFile {
  const { frontmatter, body } = splitFrontmatter(text);
  // 첫 줄이 '---'인데 닫는 '---'가 없으면 frontmatter를 쓰려다 망가진 것이다. 없는 것이 아니라 읽을 수 없는 것으로 본다 (§4).
  const opened = /^\uFEFF?---\r?$/.test(text.split('\n')[0]);
  const fm: Frontmatter =
    frontmatter !== null ? parseFrontmatter(frontmatter)
    : opened ? { state: 'invalid', reason: '닫는 `---` 줄이 없습니다.' }
    : { state: 'absent' };
  return { path, kind: fileKind(path, fm), frontmatter: fm, body, links: extractLinks(body) };
}

// ── 3. 검사 ──────────────────────────────────────────────────────────
// 4단계 공통: frontmatter 블록이 있으면 YAML 매핑으로 파싱되어야 한다 (§4, §11.1-1). 파싱 실패만 오류다.
function checkParse(f: BundleFile, issues: Issue[]): boolean {
  if (f.frontmatter.state !== 'invalid') return true;
  issues.push({ level: 'error', rule: 'yaml-parse', file: f.path, message: `YAML을 파싱할 수 없습니다: ${f.frontmatter.reason} (§4, §11.1)` });
  return false;
}

function checkConcept(f: BundleFile, issues: Issue[]): void {
  // 4단계 (완료) — 명세 §3.2·§11.1
  // v0.3: frontmatter나 type이 없는 .md는 오류가 아니라 "개념이 아닌 파일"이다. 소비자는 건너뛰고, 검증기는 경고한다(SHOULD).
  const file = f.path;
  if (!checkParse(f, issues)) return;
  if (f.kind === 'other') {
    const why = f.frontmatter.state === 'absent' ? 'frontmatter가 없습니다' : '비어 있지 않은 `type`이 없습니다';
    issues.push({ level: 'warning', rule: 'not-a-concept', file, message: `${why}. 개념이 아닌 파일로 건너뜁니다 (§3.2).` });
    return;
  }
  checkLifecycle(f, issues);
}

// 4단계 추가 (v0.3) — 소비자가 무시하거나 신선하지 않다고 볼 값을 미리 알린다. 모두 warning (§5, §11.2).
function checkLifecycle(f: BundleFile, issues: Issue[]): void {
  const file = f.path;
  const fm = frontmatterData(f)!;
  const badTime = (key: string, v: unknown) => {
    if (!isBlank(v) && parseTimestamp(v) === null) {
      issues.push({ level: 'warning', rule: 'bad-timestamp', file, message: `\`${key}: ${String(v)}\`는 허용된 시각 형식(오프셋 있는 date-time, 날짜만)이 아닙니다 (§5).` });
    }
  };
  asList(fm.verified).forEach((item, i) => {
    const o = item && typeof item === 'object' && !Array.isArray(item) ? (item as Record<string, unknown>) : {};
    if (isBlank(o.by) || isBlank(o.at)) {
      issues.push({ level: 'warning', rule: 'incomplete-verified', file, message: `verified ${i + 1}번째 항목에 by와 at이 둘 다 있어야 합니다. 소비자는 이 항목을 무시합니다 (§5.2, §11.2).` });
    } else badTime(`verified[${i}].at`, o.at);
  });
  const generated = fm.generated && typeof fm.generated === 'object' ? (fm.generated as Record<string, unknown>) : {};
  badTime('generated.at', generated.at);
  badTime('stale_after', fm.stale_after);
}

function checkIndex(f: BundleFile, issues: Issue[]): void {
  // 4단계 (완료) — 명세 §8·§8.1
  const file = f.path;
  if (file !== 'index.md') {
    // 하위 디렉터리 index.md에는 frontmatter가 없다 (§8).
    if (f.frontmatter.state !== 'absent') {
      issues.push({ level: 'error', rule: 'index-frontmatter', file, message: '하위 디렉터리 index.md에는 frontmatter를 둘 수 없습니다 (§8).' });
    }
    return;
  }
  // 루트 index.md: okf_version·title·description·license와 확장 키를 둘 수 있다 (§8.1). 모르는 키도 오류가 아니다 (§4.1).
  if (!checkParse(f, issues)) return;
  const v = f.frontmatter.state === 'ok' ? f.frontmatter.data.okf_version : undefined;
  if (isBlank(v)) {
    issues.push({ level: 'warning', rule: 'missing-okf-version', file, message: '루트 index.md frontmatter에 `okf_version: "0.3"`을 두는 것을 권장합니다 (§8.1).' });
  } else if (typeof v !== 'string') {
    issues.push({ level: 'warning', rule: 'unquoted-version', file, message: `okf_version은 따옴표로 감싼 문자열로 씁니다. 예: "0.3" (§4, §8.1). 지금 값: ${String(v)}` });
  }
}

function checkLog(f: BundleFile, issues: Issue[]): void {
  // 4단계 추가 (v0.3) — log.md에는 frontmatter가 없다 (§9, §11.1-2)
  if (f.frontmatter.state !== 'absent') {
    issues.push({ level: 'error', rule: 'log-frontmatter', file: f.path, message: 'log.md에는 frontmatter를 둘 수 없습니다 (§9).' });
  }
}

function checkLinks(bundle: Bundle, f: BundleFile, issues: Issue[]): void {
  // 5·6단계 (완료) — 명세 위반이 아니므로 모두 warning
  const file = f.path;
  for (const target of f.links) {
    const resolved = resolveLink(file, target);
    if (resolved === null) {
      issues.push({ level: 'warning', rule: 'link-outside-bundle', file, message: `\`${target}\`가 번들 루트 밖을 가리킵니다.` });
      continue;
    }
    if (target.startsWith('/')) {
      issues.push({ level: 'warning', rule: 'team/relative-links', file, message: `\`${target}\`: 팀 규칙상 번들 안 링크는 상대 경로로 씁니다.` });
    }
    if (!bundle.has(resolved) && !bundle.has(`${resolved}/index.md`)) {
      issues.push({ level: 'warning', rule: 'broken-link', file, message: `\`${target}\` → \`${resolved}\`가 번들에 없습니다. 읽기는 계속합니다 (§6.1, §11.2).` });
    }
  }
}

export function validateBundle(bundle: Bundle): Issue[] {
  const issues: Issue[] = [];
  for (const f of readBundle(bundle)) {
    if (f.kind === 'index') checkIndex(f, issues);
    else if (f.kind === 'log') checkLog(f, issues); // 날짜 제목 형식 검사는 이번 범위 밖
    else checkConcept(f, issues);                    // concept·other
    checkLinks(bundle, f, issues);
  }
  return issues;
}
