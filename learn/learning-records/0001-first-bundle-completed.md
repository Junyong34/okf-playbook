# 개념 문서와 루트 인덱스를 명세에 맞게 쓸 수 있다

레슨 0001·0002 실습(개념 3개, 루트 `index.md`)을 브라우저 검사기로 통과시켰다. 개념 문서의 필수 키 `type`, 권장 필드, 인덱스 frontmatter 규칙, 링크 경로 해석은 다시 가르치지 않고 4회차 이후 코드에서 바로 쓴다.

**Evidence**: 사용자가 0001·0002 실습을 완료했다고 보고했다(2026-11-17). 실습 결과는 브라우저에만 있어서, 저장소 `knowledge/`는 모범 답안으로 채웠다.

**Implications**: 사용자는 0001에서 정답을, 0002에서 경로 연습 답을 요청했다. 직접 계산한 결과와 맞춰 본 것인지는 확인하지 못했다. 경로 해석은 0003 테스트 2단계(`resolveLink`)로 다시 확인한다.
