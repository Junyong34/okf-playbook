# 번들 루트 경로와 저장소 루트 경로의 차이를 알고 상대 경로 규칙을 정했다

`/processes/refunds.md`를 OKF 소비자는 번들 루트(`knowledge/`) 기준으로, GitHub와 미리보기는 저장소 루트 기준으로 해석한다. 사용자는 이 차이 때문에 번들 안 링크를 상대 경로로만 쓰는 팀 규칙을 골랐다(`docs/team-rules.md`). 처음으로 "명세가 허용하는 것"과 "우리가 정한 것"을 나눈 사례다.

**Implications**: 검증기는 팀 규칙 위반을 오류가 아닌 `team/relative-links` 경고로 낸다. 4회차 검색기도 `/` 링크를 받으면 번들 루트 기준으로 해석해야 한다. 다른 소비자에게는 적합한 번들이기 때문이다.
