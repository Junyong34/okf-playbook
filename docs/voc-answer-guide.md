# VOC 답변 작성 가이드 (감성멘트)

사내 답변 템플릿 엑셀의 "감성멘트" 시트를 바탕으로 정리했다. Claude SDK로 고객 답변을 생성할 때 말투를 다듬는 데 참고한다. 정책이나 처리 절차는 문의에 해당하는 FAQ와 확인된 상담 정보를 기준으로 안내한다.

## 답변 말투

- 일반 문의에는 밝고 편안한 말투를 쓴다. 불편이나 피해를 호소하는 고객에게는 어떤 일이 있었는지 짧게 짚고 사과한다.
- 익숙한 단어를 쓰고 고객이 물어본 내용부터 답한다. 절차가 여러 단계라면 고객이 따라 할 순서대로 안내한다.
- 고객에게 필요한 행동을 정중하게 부탁한다. 선택할 수 있는 방법이라면 “괜찮으시다면”, 꼭 필요한 절차라면 “확인해 주세요”처럼 표현한다.
- 친근하고 정중한 말투를 유지한다. 고객의 감정을 짐작해 단정하기보다 문의에서 드러난 불편이나 걱정에 답한다.
- 가능한 조치를 구체적으로 알려 준다. 매장 전달, 재발 방지 조치, 회신 방법과 시점은 실제로 확인된 범위에서 안내한다.

## 쿠션어

사과나 부탁이 필요한 자리에 짧게 쓴다. 답변 하나에 비슷한 표현을 여러 번 넣으면 안내가 길어질 수 있다.

| 상황 | 참고 표현 |
| --- | --- |
| 답변이 늦었을 때 | 기다리게 해 드려 죄송합니다. |
| 고객에게 확인을 부탁할 때 | 번거로우시겠지만 주문 내역을 확인해 주세요. |
| 고객이 선택할 수 있는 방법을 제안할 때 | 괜찮으시다면 다른 방법을 안내해 드리겠습니다. |
| 요청을 받아들이기 어려울 때 | 요청하신 방법으로는 처리하기 어렵습니다. |

“죄송합니다만”, “불편하시겠지만”, “이해해 주신다면”, “안타깝지만”으로 말을 꺼내기 전에 사과가 필요한지, 고객이 해야 할 일이 있는지부터 확인한다. 제한 사항을 안내할 때는 확인된 이유와 가능한 방법을 덧붙인다.

## 상황별 표현

| 상황 | 참고 문장 |
| --- | --- |
| 이용 중 불편을 겪었을 때 | 이용 중 불편을 드려 죄송합니다. |
| 고객이 불편했던 이유를 설명했을 때 | 말씀해 주신 상황이라면 이용하시면서 불편하셨을 것 같습니다. |
| 문제가 생겼다는 사실을 확인했을 때 | 그런 일이 생겨 안타깝습니다. |
| 답변이 늦었고 지금 안내할 수 있을 때 | 답변이 늦어 죄송합니다. 확인한 내용부터 안내해 드리겠습니다. |
| 매장에 전달하고 재발 방지를 요청할 수 있을 때 | 매장 책임자에게 내용을 전달하고 같은 일이 반복되지 않도록 확인을 요청하겠습니다. |
| 지금 확인할 수 있는 정보가 부족할 때 | 현재 정보만으로는 문의하신 내용을 확인하기 어렵습니다. |
| 추가로 도와드릴 수 있는 방법이 없을 때 | 요청하신 부분은 추가로 도와드리기 어렵습니다. 도움을 드리지 못해 죄송합니다. |
| 담당자 확인 후 연락할 수 있을 때 | 담당자가 확인한 뒤 문자나 전화로 안내해 드리겠습니다. |
| 식품 때문에 불편을 겪었을 때 | 맛있게 드셨어야 할 음식인데 불편을 드려 죄송합니다. |
| 쇼핑 중 불편을 겪었을 때 | 쇼핑하시는 동안 불편을 드려 죄송합니다. |
| 제품 관련 논란으로 걱정을 전했을 때 | 관련 소식을 접하시고 걱정되셨을 것 같습니다. 확인한 내용을 안내해 드리겠습니다. |
| 건강을 위해 쓰는 제품을 걱정할 때 | 건강을 위해 쓰시는 제품이라 더 걱정되셨을 것 같습니다. |
| 의견을 남겼을 때 | 의견을 들려주셔서 감사합니다. |
| 바로 반영하기 어렵지만 매장에 전달할 수 있을 때 | 바로 반영하기는 어렵지만 말씀해 주신 내용은 매장에 전달하겠습니다. |

“항상 노력하겠습니다”, “더 나은 서비스를 제공하겠습니다” 같은 마무리는 실제로 안내할 조치가 있으면 그 조치를 적는 편이 좋다. 예시의 주문 내역, 담당자, 문자, 전화 등은 문의에 맞게 바꿔 쓴다.

## 계절 인사

계절 인사는 일반 문의나 감사 인사에 자연스럽게 어울릴 때 짧게 덧붙인다. 불편이 해결되지 않았거나 고객이 처리 결과를 기다리는 상황에서는 현재 상태와 다음 안내를 먼저 전한다.

- 초가을에는 “하늘이 맑고 바람이 선선해졌습니다. 편안한 하루 보내세요.”
- 가을에는 “가을이 깊어갑니다. 여유로운 하루 보내세요.”
- 겨울에는 “추운 날씨에 따뜻하게 지내세요.”
- 연초에는 “새해에도 여유롭고 풍성한 한 해 보내세요.”
