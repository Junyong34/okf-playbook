# 번들 작성 팀 규칙

OKF v0.2 명세 위에 이 실습에서 추가로 정한 규칙이다. 명세가 허용하는 것을 오류로 만들지 않으며, 위반은 `validate.ts`가 경고(`team/*`)로 보고한다.

| 규칙 | 근거 | 검사 |
| --- | --- | --- |
| 번들 안 링크는 상대 경로로 쓴다 (`../processes/refunds.md`). `/`로 시작하는 번들 루트 기준 경로는 쓰지 않는다. | 명세는 번들 루트 기준 경로를 권장하지만(§6.1), GitHub·에디터 미리보기는 `/`를 저장소 루트로 해석해 링크가 깨진다. 번들이 저장소 하위 디렉터리 `knowledge/`에 있기 때문이다. (2026-11-17, 레슨 0002) | `team/relative-links` |
